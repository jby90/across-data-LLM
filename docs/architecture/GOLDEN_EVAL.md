# 五国黄金样本评测（检索召回 / 条款定位 / 事实一致性）

## 构成
- `backend/app/analysis/golden_spec.py`：题目与期望条款的数据层（国家、文书、条号只在此处）。
- `golden_cases.json`：冻结评测集。55 个主题 × 3 种问法（关键词、业务场景、数据类型）= 165 题，五国均覆盖；每个期望条款冻结原文 SHA-256。
- `golden_eval.py`：评分与门槛；`golden_cli.py`：命令行；`tests/test_golden_eval.py`：无需数据库的单测。

## 复测
在 `backend` 目录，环境变量同接手文档第 5 节：
```
uv run python -m app.analysis.golden_cli build                      # 语料变化后重新冻结
uv run python -m app.analysis.golden_cli run --mode retrieval --out <目录>            # 仅稀疏检索，不调模型
uv run python -m app.analysis.golden_cli run --mode retrieval --planning --out <目录> # 生产检索规划
uv run python -m app.analysis.golden_cli run --mode full --out <目录> --concurrency 3 # 检索 + 引用 + 事实一致性
```
`full` 约 60 分钟。每次模型请求都会写出站审计记录（系统既有行为）。

## 指标口径（运行前确定，未按结果调整）
- 召回率：每题若干“必备条款组”，前 5 条命中任一等价条款即算该组命中；分子/分母为组数。
- 条款定位准确率：生成的结论所引条款落在该题期望条款内的比例（严格：未列入的相关条款算错）。
- 事实一致性：独立模型判断结论被引文完整支持（llm_judged，非律师）；只统计通过程序核验的结论，另列覆盖率。
- 未测量为“未测量”，不计达标。条款原文缺失或变化记为“来源漂移”，按未命中。
- 同一法律的另一语种/抄本，在条首出现同一条号标题时视为等价（突尼斯、黎巴嫩，39 处）。

## 2026-10-29 结果（开发库，165 题，生产检索规划 + 生成 + 判定）
| 指标 | 目标 | 结果 | 状态 |
|---|---:|---:|---|
| 召回率 | ≥90% | 86.2%（269/312） | 未达标 |
| 条款定位准确率 | ≥80% | 55.7%（272/488） | 未达标 |
| 事实一致性 | ≥90% | 96.7%（411/425），判定覆盖 87.1% | 达标 |

分国家召回：新加坡 90.9%、摩洛哥 90.7%、突尼斯 87.5%、黎巴嫩 86.3%、埃及 76.8%。分问法：业务场景 92.3%、关键词 87.5%、数据类型 78.8%。分维度召回最低为 D6（违规处罚）70.8%。不调模型的纯稀疏检索召回为 48.7%。技术错误 2 题（均如实记录）。原始结果见 `golden_eval_20261029/`。

## 已查明的原因与限制
- 定位准确率偏低主要因为严格口径：多数“未命中”引用的是同一法律中未列入期望的相关条款；新加坡另有 15/92 条引用来自咨询指引而非法条。期望条款每题仅列最核心条文，未经律师复核。
- 新加坡库内同时存在 2012 年原始版 PDPA（法律状态“未知”）与 2021 修订版，可被检索引用；黎巴嫩第二份抄本来自非官方站点。
- 期望条款与题目在阅读原文后撰写，部分关键词题沿用了译文用词，关键词题召回可能偏乐观。
- 埃及（物联网框架以页码为条号）和 D6 处罚类问题召回最低，尚未针对性改进。
