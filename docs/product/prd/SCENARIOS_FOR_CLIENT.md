# 想先和您确认：报告要覆盖哪些情形

您提到业务是双向的，既有车企出海，也有外国企业进来。我们按数据往哪个方向流，把情形分成四类，想请您看看有没有漏的，以及先做哪一类。

| 类别 | 典型情形 | 报告主要回答什么 |
|---|---|---|
| A. 数据从中国出去 | 国内车企把境外车辆的数据回传国内；国内数据提供给境外的合作方 | 中国出境要走哪条路径（申报、备案、认证，或不需要），再加上对方国家的要求 |
| B. 在海外本地经营 | 在新加坡等地卖车，本地收集、使用车主和车辆数据 | 当地法律怎么规定：同意、保护、保留、泄露上报 |
| C. 数据流入中国 | 境外车企或供应商把数据传到中国，或境外数据回传中国处理 | 来源国对出境的限制，加上数据到中国之后适用的规则 |
| D. 外国车企在中国经营 | 外国车企在中国收集用户数据，并传给境外总部 | 中国境内规则，加上中国出境规则 |

示例报告属于 B 加 A 的一部分：在新加坡卖车，数据回传中国。

## 想请您回答的三个问题
1. 这四类里，有没有您实际会遇到、但没写进来的情形？
2. 如果只能先做两类，您希望先做哪两类？
3. 一份报告里，是把四类放在一起讲，还是每类单独一份更方便您的客户使用？

## 一点说明
中国出境的具体门槛和路径，我们会以官方原文为准，原文入库后再写进报告，不凭印象写。示例报告里这部分标了“需补充”，这是有意为之。
