## 1. 甲方要什么

中国汽研内部课题，面向车企/主机厂市场化推广，2026-11-30 交付。两个成果：

1. **多法域汽车数据跨境知识图谱/知识库**：官方权威来源；6 类要素、12 类关系、12 类属性；外文保留原文并附准确中文对照；全生命周期版本管理和版本对比；图谱运维后台（导入、编辑、校验、日志）；≥450 条制度、≥300 条标准；完整率、准确率均 100%。
2. **合规报告智能生成工具**：30 国固定八维度洞察报告（在线预览、Word/PDF、法规变更后同步）；8 类合规文件（出境评估申报表、风险评估报告、合同模板、整改跟踪、准入材料清单、DPIA、LIA、TIA）；法规动态监测（30 天入库、72 小时同步与推送）；指标：召回≥90%、事实一致性≥90%、法条定位≥80%、舆情分级≥90%；版本追溯与不可篡改审计日志；准入业务模块；四级角色、检索、批量、消息中心。

**当前口径（以最新为准）**：首批试点五国——新加坡（先打通端到端）、埃及、突尼斯、摩洛哥、黎巴嫩；采用 DeepSeek 等外部 API，不微调；五类智能体（采集、知识构建、合规分析、报告编排、更新跟踪）经 MCP 工具协同；外文翻译允许大模型生成但须标注机翻并核验关键字段；人工法律复核由甲方要求乙方委托第三方完成。未决：试点五国与原 14 范围/30 国清单如何衔接。

**界面补充要求**：必须在现有平台内实现，页面 1–6（法规中心、法规详情含关联关系面板、知识图谱管理含质量视图与核对标记、合规分析工作台、国别报告含版本对比与导出、任务过程时间线）；中文业务用语；未核对内容标“待核对”，机翻标“机器翻译”。

**法律术语库设想**：优先取法律自带定义，再官方指南/官方他语版本/国际通行用法；翻译强制按术语库并由程序检查；无对应概念保留原词加解释；跨国复用。

## 2. 系统现状

技术栈：Vue 3 + Element Plus（用户端、管理端两个应用）/ FastAPI + Python 3.12 / PostgreSQL 16（RLS）/ Alembic（迁移到 0023）/ Docker Compose + nginx。线上版本 `country-015c103`。

- **采集**：发现→下载→SHA-256 内容寻址归档→解析→条款切分；robots、SSRF 防护、限速、站点条款批准门禁；PDF 文字层 + Tesseract OCR（eng/ara/fra）；调度用 `SKIP LOCKED`。五国现有 81 文档/81 版本/2,744 条款。
- **知识**：6 要素 12 关系有 DB 约束；LLM 抽取后经逐字证据、类型矩阵、语义规则、独立裁判四道闸门；人工审批不被机器覆盖，改为提案；翻译用占位符保护数字、术语库强制、译后四项检查。
- **分析**：采集事实→检索（BM25+RRF，可选语义规划）→八维分析（选证据/写结论/核验支持度三阶段）→程序核验（可退回最多 2 轮）→编制；分析中可追问（最多 2 轮，仅重跑受影响维度）；SSE 进度；Word/PDF/ZIP 导出；模型出站脱敏与审计；工作流版本化配置（Agent Studio）。
- **更新**：来源观察→版本变更→影响项（72 小时 due_at）→站内通知。
- **前端**：用户端（聊天分析、法规知识库含关系解读、术语、通知、成员）；管理端（文档、翻译复核、知识图谱、Agent Studio、更新时效、站点、企业、账号）。
- **验收状态**：工程原型已部署；人工法律复核 0/32；埃及清晰原文缺口；容量未验证。

## 3. 差距与风险（按优先级）

**对照甲方需求**
1. 8 类合规文件无实现（代码只有 6 种文档类型，属法规分类，不是合规文件类型）。
2. 图谱属性只有 8 项，甲方要 12 项；`violation_level` 无填充逻辑，多项恒为“待核查”。
3. 版本对比缺：无条款级 diff 接口与界面；报告对比仅最早 vs 最新两版。
4. 审计日志不完整：无登录/导出/编辑统一操作日志；`DELETE tasks/{id}` 级联硬删除报告与轨迹。
5. 72 小时联动只到提醒与影响记录，不自动重分析；站点默认每 7 天抓取一次，检测延迟吃掉时效；手工上传不产生变更记录。
6. 准确率类指标：人工金标 0；召回 31/32 依赖默认关闭的 semantic_planning；引文通过 53/64。
7. 准入业务模块、舆情筛选分级、批量与订阅、30 国覆盖：未见实现。
8. 界面补充要求缺口：法规中心多维筛选；质量视图问题项可定位清单；任意两版对比与逐句高亮；用户端任务时间线；表单+结果表格式分析工作台。

**工程风险**
- OCR 每份最多 40 页，超出静默丢弃但标记已解析；站点租约 30 分钟可能超时被重复领取。
- 通用性违规：写死的五国、新加坡检索词/主机、场景与事实槽（`discovery.py`、`bindings.py`、`cli.py`、`chat.py`、`workflow_engine.py`、`extractor.py` 种子数据）。
- `POST /review-points/import` 缺律所回复时用暂拟口径填充并保持 confirmed。
- 分析任务是进程内 asyncio，重启丢失；脱敏不覆盖人名、可被运维关闭。
- 网关无 HSTS/限流/CSP；无自动备份；CI 无端到端测试；`DEPLOY.md` 迁移版本滞后。
- 本机运行记录：Windows 下测试需 `dev-tools/win_mkdtemp_acl.py` 补丁（见 DEVICE_MIGRATION_DEPLOY_20261027.md）。
