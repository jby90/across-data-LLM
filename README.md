# 车研数合 — 汽车数据跨境合规平台

面向汽车企业法务、数据合规与海外认证团队的多租户汽车数据跨境合规平台（2026年11月28日结项正式版），围绕三大核心业务模块构建全链路闭环：

1. **法规知识库**：覆盖全球 **46 个主权国家与地区**（中国 + 五大洲 45 个海外国家与地区）**452 部现行有效可用官方法规**（27,715 条可用条文，27,404 条外文条文 100.0% 通过六道确定性翻译门禁）、**311 项现行与即将实施汽车技术标准**（中国标准 148 项 + ISO/UNECE/IEC/SAE/ITU 国际通用标准 163 项）、五道门禁知识图谱（**17,113 个可用要素节点**与 **16,321 条逐字引文锚定激活关系**，含量化罚则保真）及 **45 国固定八维度国家合规简报**（支持分节在线修订、人工审核归档防漂移锁定、按受影响章节增量更新与历史版本一键回退）。
2. **合规评估**：支持多选预设场景及直接输入添加自定义业务场景，自动核定数据出境法定路径并生成 **8 类标准化合规评估文书**（含国家网信办 4 套官方申报原表与欧盟标准英文 DPIA 范本）及八维度咨询报告；支持上传内部制度缺口诊断、停止编辑自动生成带日期历史版本与按日期一键回退、咨询对话一键复制与归档冻结保护，并全量打通 **中文、英文及法、德、西、葡、意、荷、印尼、土、波、日、韩、泰、越、阿、俄共 17 种官方语言** 在线预览与 Word、PDF、Excel、整包压缩导出（外文正式件零未译中文残留）。
3. **海外属地准入**：覆盖 **98 项现行可用海外属地准入事项** 与全平台 **25 套已锁定指纹法定申报原表**（海外五国 20 套 + 中国国家网信办 4 套 + 欧盟标准英文范本 1 套），支持多业务场景并集筛查、综合申报材料按事项自动拆分、阿拉伯文/英文/法文等东道国法定受理语种正式申请书生成及获批证照到期预警台账。

平台分为 **用户端**（企业用户/编辑者、企业普通查看者/只读受控且下载开关按账号独立配置、门户单点登录与公开自助注册独立体验用户）与 **管理端**（平台超级管理员 16 项导航菜单、运维管理员 13 项脱敏内容运维菜单），五类身份首屏统一搭载 **唯一旗舰深海合规态势看板**（支持 180 国密度热力、五大洲镜头推近、图谱六维雷达、风险初评至当前压降对比与 1920×1080 视口内无弹窗全屏汇报）。

## 目录结构

```
backend/       后端异步服务、法规解析翻译图谱与多语种文书引擎（Python 3.12，Alembic 迁移至 0078）
apps/          前端工作区（pnpm workspace）：web-user 用户端（5174）、web-admin 管理端（5175）
packages/      前后端共享组件、46 国目录、矢量国旗与统一公文主题样式（packages/shared）
deploy/        容器编排、2GB 轻量云自适应零交换分区运行网关与一键私有化部署脚本
docs/          架构设计、开源与字体许可证合规、46 国法规来源使用条款登记文档
scripts/       许可证门禁、前端测试套件与工程核验脚本
data/          多国权威法规种子、中外汽车技术标准目录与 25 套官方申报原表资产
```

## 本地开发与自动化门禁

```powershell
# 1. 后端（注意：虚拟环境须放在纯 ASCII 路径，嵌入式测试数据库在含中文路径下无法初始化）
cd backend
$env:UV_PROJECT_ENVIRONMENT = "C:\Users\<你>\.venvs\cyshuhe"
uv sync --python 3.12
uv run ruff check .
uv run pytest -q   # 159 个可执行测试模块（1,664 项收集用例）

# 2. 配置（真实密钥仅放环境变量或未跟踪的 .env，严禁提交入库）
copy ..\.env.example ..\.env   # 填写高强度随机 CYSH_JWT_SECRET 与 CYSH_PORTAL_SSO_SECRET

# 3. 数据库迁移与创建平台管理员（密码至少 12 位）
uv run alembic upgrade head    # 升级至最新 0078 版本
uv run python -m app.cli create-platform-admin --email admin@example.com

# 4. 启动后端服务（8000）与后台定时采集巡检进程
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
uv run python -m app.worker    # 常驻执行 168h 错峰巡检与 24h 舆情抽取；加 --once 只执行单轮

# 5. 前端构建、单测与双端热更新服务
cd ..
pnpm install
node --test scripts/test*.mjs packages/shared/tests/countryFlags.test.ts   # 10 个前端套件（54 项用例）
pnpm dev:user    # 用户端 http://127.0.0.1:5174
pnpm dev:admin   # 管理端 http://127.0.0.1:5175
```

## 官方信源礼貌采集与存证规范

管理端「采集站点」新增官方站点（默认停用）→ **核验并确认来源使用条款、写明授权依据** 后方可启用 → 后台按 168 小时每周错峰计划定时巡检 → 严格遵守 `robots.txt` 礼貌限速下载（体积上限保护与内网地址阻断）→ 原件按 SHA-256 内容哈希不可变归档 → 物理坐标版面解析与双边对称清洗 → 切分条款并经六道门禁精译入库。源站内容修订时自动生成新版本并触发 72 小时影响联动，历史版本与审计存证完整保留。
